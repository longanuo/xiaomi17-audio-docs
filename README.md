# 小米17外放音质与音效调校方案

面向小米17标准版（设备代号 `pudding`）的外放调校记录，包含沉浸声配置、鼓点厚度调整、中低音量补偿，以及安装、自检和回退方法。

作者：林河。当前整理版本：**v1.5.6，仅机型校验版**。文档整理日期：2026-10-21。

“类哈曼”用于描述调音目标；本项目没有哈曼卡顿官方调音或认证，不承诺复现小米10S或其他设备的声音。

## 当前版本做了什么

- 沿用 v1.5.4 的四份音频配置，保留沉浸声相关调整、鼓点厚度调整和中低音量补偿。
- 安装时精确校验 `ro.product.device=pudding`，其他机型拒绝安装。
- 取消旧版的系统版本限制，系统版本只记录在日志与自检中。
- 保留配置文件存在性、权限和 SELinux 标签检查，以及开机覆盖校验。

**取消系统版本限制，不代表所有系统版本都经过兼容性验证。** 本版仍覆盖来自既有基线的整份配置；跨系统时，可能同时覆盖新系统在这些文件中新增或调整的原厂条目。

## 安装与自检

适用范围为小米17标准版 `pudding`，以及手机上已经正常工作的 SukiSU / KernelSU 模块管理环境。其他机型和管理器组合未列入本次验证范围。

1. 如已提供 Release 附件，下载 `xiaomi17-audio-v1.5.6.zip`，通过模块管理器安装，然后重启。
2. 本版模块 ID 为 `xiaomi17-stock-safe-audio`。相同 ID 的旧版按管理器正常更新流程处理，避免同时启用其他外放调音模块。
3. 查看手机上的 `/sdcard/Download/xiaomi17_audio_mod_selfcheck.txt`，确认版本为 `1.5.6`，开机标记为 `version=1.5.6 ok=1`。
4. 继续核对实际媒体音量曲线、音效加载日志和播放表现。文件一致与挂载成功，只能证明对应文件检查通过。

## 验证状态

已有电脑端记录包括包结构与 CRC、配置一致性、脚本语法和模拟安装条件检查。近期同版本 ZIP 的多套一层目录问题已修复，`module.prop` 位于 ZIP 根目录。

现有记录没有证明 v1.5.6 已完成实机刷入、跨系统兼容性测试或客观声学测量。听感改善仍需在具体手机、系统和应用上验证。

## 回退与反馈

临时排查可先停用模块并重启；完整移除应在管理器中卸载并重启，卸载脚本会尝试恢复已备份的持久音效状态。若重装旧版，选择此前在同一手机与系统上验证过的包。

反馈时请注明机型、系统完整版本、模块管理器与模块版本、播放应用、音量位置、沉浸声开关和具体表现。附自检或诊断片段前，请先检查并遮盖其中的个人信息。
