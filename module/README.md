# 小米17外放音效 v1.5.6：仅机型校验版

作者：林河。设备：小米17标准版，代号 `pudding`。

按作者要求，安装条件只校验机型，不再限制系统版本、Android API、ROM 渠道或音频配置白名单。系统版本仅显示在安装日志和自检报告中，不参与是否允许安装的判断。

## 与旧包的区别

- 基于 v1.5.4，删除只允许 `OS4.0.0.31.XPCCNXM` 安装的判断。
- 机型使用 `ro.product.device=pudding` 精确匹配；其他机型仍拒绝安装。
- 四份音频 JSON/XML、`system.prop` 和调音开关与 v1.5.4 逐字节相同，沿用沉浸声、鼓点厚度和中低音量补偿。
- 保留包内文件完整性、权限和 SELinux 标签检查。这些检查不限制系统版本。
- 不采用 v1.5.5 的配置白名单检查；不因音频配置与旧系统不同而拒绝安装。

## 安装

1. 将 `xiaomi17-audio-v1.5.6-device-only.zip` 发给使用小米17标准版的用户。
2. 在已正常工作的 SukiSU / KernelSU 模块管理器中选择此 ZIP 安装，然后重启。
3. 模块 ID 仍为 `xiaomi17-stock-safe-audio`，可按管理器正常流程覆盖旧版，不需同时启用多个版本。
4. 重启后查看 `Download/xiaomi17_audio_mod_selfcheck.txt`，版本应为 1.5.6，开机挂载标记应为 `version=1.5.6 ok=1`。仍需核对实际运行曲线和播放效果。

取消安装限制不代表每个系统版本的音频行为均已验证。本版直接沿用 v1.5.4 的整份音频配置，跨系统时也会覆盖这些配置内的其他原厂条目；未逐一验证各系统版本的兼容性。安装成功、文件一致均不等于音效引擎已经加载或听感一定改善。

## 回退

停用本模块并重启。若要重装旧版，应选择原先已在该手机及系统上验证过的包。
